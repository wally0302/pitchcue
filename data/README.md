# data/ — 專案背景資料

把你要讓 AI 參考的資料放在這個資料夾：

- `*.md`（或 `*.txt`）：全部會依檔名排序後合併，塞進 AI 的 system prompt。
  建議檔名前加編號控制順序，例如 `01-專案簡介.md`、`02-技術架構.md`、`03-商業模式.md`、`04-常見問題.md`。
- `glossary.txt`：一行一個專有名詞（專案名稱、技術名詞、人名、縮寫）。
  會用在語音辨識的 keyword 提示與問題整理，讓評審講到的名詞不會被聽錯。

修改後：本機 `npm run dev` 會自動重新產生；部署到 Vercel 只要 `git push` 就會重新 build。

`example.md` 是佔位範例，放入真實資料後請刪掉。
