# 小字講稿單屏設計

## 目標

讓手機講稿的「小字」模式在 iPhone Chrome 的單一視窗內盡量完整顯示每頁內容，不需要上下捲動；中字與大字模式維持原樣。

## 已核准方案

- 小字正文調整為 18px、緊湊行高與段落間距。
- 小字模式同步縮減講稿卡片、標題區與正文區的垂直內距。
- 保留計時器、頁碼、翻頁按鈕與標題，不隱藏操作資訊。
- 以 390 × 844 手機視窗逐頁檢查 14 頁講稿。

## 驗證

1. JSON 仍有 14 頁且沒有舞台提示。
2. 小字模式逐頁內容不超出可視講稿區。
3. Lint、TypeScript 與 production build 通過。
