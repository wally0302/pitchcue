# PitchCue 變現 Roadmap（12 個月）

最後更新：2026-09-13

## Context

PitchCue 一開始是為 2026-09-13 黑客松做的「評審問答即時提詞」工具：錄下問題 → 轉錄 → 用自己的簡報資料生成「重點 + 口語稿」，隊友在手機上同步看。

目標：**以在職工程師身分、每週 5-10 小時，12 個月內做成月入 NT$1-3 萬的半被動收入。**

產品的核心能力不是「即時回答」，而是「**用你自己的資料，當場生出一份可以直接唸的話**」。適用情境要通過兩個篩子：

1. 回答者手上有專屬資料（產品手冊、簡報、擬答文件）。
2. 提問的人接受你看小抄。

第二個篩子決定商業化成敗，也是道德紅線。黑客松只是第一個案例，正式定位改為：**前線問答 copilot，任何要當場回答問題的人，手機上都有一份照著唸的答案。**

## 一、現況診斷

### 手上有什麼
| 資產 | 狀態 | 對變現的意義 |
|---|---|---|
| 可用的產品 | 已部署 Vercel、黑客松實戰過 | 有 demo、有真實使用故事 |
| 舞台 UX（手機直式、口語稿 22px、隊友同步、零閒置流量） | 完成 | ChatGPT 語音模式做不到的差異化 |
| `build-knowledge-docs` skill | 完成 | 「把資料整理成擬答文件」的流程，可直接當服務賣 |
| 開源 repo + 一鍵部署 | 完成 | 是行銷通路，也是付費的競爭者（見風險） |

### 收錢前必須補
- 沒有帳號與多租戶：一次部署 = 一個團隊，目前只有單人 email + 密碼登入（`lib/session.ts`，HMAC cookie，名單在 `ALLOWED_EMAILS`）
- 知識文件在 build 時打包（`scripts/build-knowledge.mjs` → `lib/knowledge.generated.ts`），使用者無法自己上傳
- 沒有付費、沒有用量計量
- Vercel Hobby 方案禁止商用，要升 Pro（約 US$20/月）

### 三個層次的意義

**Tier 1 是真正的商業化方向，月訂閱在這裡才成立。** 黑客松和口試一年用一次，撐不起訂閱；但展場工讀生和保險業務每天都在被客戶問「這個和那個差在哪」「解約扣多少」，他們有公司的產品手冊，客戶不介意他們低頭查。頻率高、付費方是公司、現場使用合法。國外的 Balto、Cresta 做的是英文、電話整合、賣大企業的客服中心版本；台灣中小型保險經紀、房仲加盟店、車商展間這一段，用手機就能跑的繁中版本是空的。

展場是切入點，因為它和現在的產品幾乎一樣：一場活動、一組資料、一群人同步看、按場收費。先找一家要參展的廠商，用現有版本幫攤位團隊跑一場，驗證「公司願意為前線員工的即時答題付錢」，再決定要不要往業務話術 copilot 走。

**Tier 2 是半被動收入的引擎。** 台灣升學面試一年三波：四五月大學個人申請面試，十到十一月研究所推甄，六七月與十二一月論文口試。大學申請面試每年約十萬名高中生，家長願意付錢，補習班本來就在賣幾千元的面試培訓。走法是和補習班、高中輔導室合作（B2B2C），不是自己一個個賣給學生。求職面試練習市場更大，但 Yoodli、Final Round AI、Google Interview Warmup 都在做，只當練習引擎的附帶場景。

**Tier 3 是高單價、低量的服務生意。** 公關公司在記者會前本來就寫「擬答」，IR 部門法說會前也一樣，這和 `build-knowledge-docs` 的產出一模一樣。一份可收數萬元，但要靠人脈談，不是被動收入。適合當 Phase 0 的手動服務對象，因為他們付得起、也最能驗證擬答品質。

**不做的那一排要明講。** 面試中即時提詞技術上和黑客松一樣，市場也有人在賣，但雇主發現就是全面封殺，產品會被貼上作弊標籤，連練習模式的口碑都會被拖累。不值得冒品牌風險。

### 定價建議（起始值，驗證後調整）
| 方案 | 對象 | 價格 |
|---|---|---|
| 單場通行證 | 比賽、口試、單次面試 | NT$390，含 7 天練習 + 當天現場模式 |
| 旺季包 | 升學面試季 | NT$690，30 天不限場次 |
| 展場方案 | 參展廠商 | NT$3,000-8,000 / 場，整攤位共用 |
| 機構方案 | 育成中心、補習班、輔導室 | NT$4,000-8,000 / 月，10-30 組使用者，含後台 |
| 前線月費 | 保險、房仲、車商團隊 | NT$300-500 / 人 / 月（Tier 1 驗證後才推出） |
| 免費層 | 試用 | 文字輸入、看 3 題答案；不給語音、不給隊友同步 |

### 達標算式（月入 NT$2 萬的兩種組合）
| 組合 | 內容 | 金額 |
|---|---|---|
| B2C 為主 | 30 張通行證 × NT$390 + 2 家機構 × NT$4,000 | NT$19,700 |
| B2B 為主 | 2 場展場 × NT$5,000 + 1 個 25 人前線團隊 × NT$400 | NT$20,000 |

### 單位經濟（估算）
- 一場約 20 題 × （轉錄 + 30k 字快取 context 回答）≈ 每場 OpenAI 成本 NT$30-60。
- 練習模式每題成本相近，每張通行證上限 150 題以防被刷。
- 固定成本：Vercel Pro 約 NT$650/月、Upstash 免費層可撐到數千場、網域約 NT$500/年。
- 毛利率約 80-85%。**成本不是問題，取得客戶才是。**

## 三、12 個月 Roadmap

時間預算：每週 5-10 小時，全年約 300-450 小時。原則是**每個階段先賺到錢或拿到證據，才做下一階段的工程**。

### Phase 0：驗證（第 1 個月，約 30 小時）
目標：不寫新功能，先確認有人願意付錢。

1. **黑客松是第一份證據。** 記下：用了幾題、有沒有照著唸、隊友覺得值多少錢。寫成「我怎麼用 AI 準備評審問答」的文章（Medium / Threads / Dcard），附 demo 影片。
2. **手動賣服務，不賣軟體。** 用 `build-knowledge-docs` skill 幫 5 個對象做「擬答文件 + 模擬 50 題」，收 NT$1,500-3,000 / 份。對象混搭：學生或競賽團隊 3 個，公關公司或參展廠商 2 個。
3. **跑一場真實的 B2B 現場。** 找一家要參展的廠商，用現有版本幫攤位團隊跑一場，收 NT$3,000-8,000。這是驗證 Tier 1 最便宜的方法。
4. **landing page + 預購**（靜態頁即可）：展場、升學面試、競賽三個版本的文案，收 email 預約。
5. 訪談 10 個人：3 個學生或家長、2 個競賽團隊、2 個展場或業務主管、2 個補習班或輔導老師、1 個公關。每人 20 分鐘，問：上次最怕什麼、現在怎麼準備、願意花多少錢。

**通過門檻**：至少 3 個人付錢買手動服務，或 30 個 email 預約。
**放棄門檻**：沒人願意付錢，且訪談都說「不會為這個花錢」→ 當作品集，不再投入。

### Phase 1：可收費的自助版 MVP（第 2-4 個月，約 100 小時）
目標：使用者不用你介入，能自己上傳資料、練習、付錢。

工程項目（依優先序）：
1. **帳號**：email magic link（不做社群登入），取代目前單人 email + 密碼的 `ALLOWED_EMAILS` 名單。
2. **執行時知識庫**：上傳 PDF/PPTX/MD → 伺服器端抽文字 → 存 Upstash → 送進 prompt。沿用 context stuffing 與 prompt cache，不做 RAG。`scripts/build-knowledge.mjs` 的邏輯搬到 API 路由。
   **設計決定**：知識庫要掛在「組織」下而不是「個人」下，支援多人共用、由管理者更新。黑客松版本是一人一份，Tier 1 需要一家公司一份、多個前線人員讀。現在就留這一層，不然走不到 Tier 1。
3. **練習模式**：從資料生成 30-50 題可能問題，語音作答，AI 給評分與建議。這是 `build-knowledge-docs` 第 07 步的自動化，也是留存與口碑的核心。
4. **付費**：先用 Lemon Squeezy 或 Gumroad；台灣信用卡問題多再換藍新 / TapPay。用量計量：每張通行證扣題數。
5. 房間碼改為每帳號或每組織自動產生；升級 Vercel Pro。

**通過門檻**：付費自助用戶 ≥ 10 人，至少 3 人是陌生人；或拿到 1 家展場 / 前線客戶的第二次付費。
**放棄門檻**：Phase 0 預約名單轉換率 < 5% 且付費者全是熟人。

### Phase 2：分發與旺季（第 5-8 個月，約 120 小時）
目標：讓客戶自己找上門。**十到十一月研究所推甄、十二至一月論文口試是 12 個月內最重要的營收窗口，Phase 1 必須在 10 月前完成。**

1. **SEO 內容（半被動收入引擎）**：每兩週一篇，鎖定長尾關鍵字：「大學面試 常見問題」「研究所推甄 面試 評審會問什麼」「論文口試 問答」「創業競賽 評審 Q&A」「展場 解說員 話術」。每篇文末給免費的「輸入你的題目，看 3 題模擬問答」。
2. **升學與競賽行事曆頁面**：整理三波升學面試日期與全台創業競賽、黑客松日期，賽前兩週自動寄提醒信。
3. **B2B2C 通路**：找 2-3 家面試補習班或高中輔導室談機構方案，先給一期免費換案例。
4. **Tier 1 試點**：帶著 Phase 0 展場案例，找 1 家保險經紀、房仲或車商團隊試前線月費。
5. **推薦機制**：`/view` 頁面本身就是廣告，加「這個團隊用 PitchCue 準備，你也來試試」。

**通過門檻**：旺季單月營收 ≥ NT$10,000，自然流量占新用戶 ≥ 30%。

### Phase 3：轉半被動（第 9-12 個月，約 80 小時）
目標：把你的時間從營運抽出來。

1. 客服自動化：FAQ、失敗重試、退款規則自動化。
2. **依 Phase 2 數據決定主力**：Tier 1 有客戶續約 → 做組織後台、多人管理、資料版本更新，往前線 copilot 走；Tier 2 占比高 → 補四五月大學申請面試季的內容與補習班通路。兩邊都不夠 → 只留 B2C 練習模式當被動收入，停止工程。
3. 四五月大學申請面試季前，把 Phase 2 的內容與 email 序列重跑一次。

**12 個月結算目標**：連續 3 個月 ≥ NT$15,000，每週投入 ≤ 3 小時。

## 四、產品缺口對照表（給 Phase 1 用）

| 缺口 | 目前 | 改成 | 相關檔案 |
|---|---|---|---|
| 認證 | 單人 email + 密碼、HMAC cookie session（`ALLOWED_EMAILS` 名單） | 每人 magic link session | `lib/session.ts`、`lib/auth.ts` |
| 知識來源 | build 時打包成常數 | 上傳 → 抽文字 → Upstash → 執行時組 prompt | `scripts/build-knowledge.mjs`、`lib/knowledge.generated.ts`、`app/api/answer/route.ts` |
| 知識庫層級 | 全站一份 | 組織 → 知識庫 → 多個成員讀；管理者可更新 | 新增資料模型 |
| 房間 | 單一 `ROOM_CODE` | 每帳號或每組織自動產生、6 小時 TTL 維持 | `lib/room.ts`、`app/api/room/link/route.ts` |
| 練習模式 | 無 | 新頁面 `/practice`：出題、語音作答、評分 | 新增；出題風格沿用 `lib/prompts.ts` 的 ANSWER_SYSTEM |
| 輸入方式 | 語音為主 | 語音 + 文字並列（前線與直播場景以文字為主） | `app/page.tsx` |
| 付費與計量 | 無 | 通行證 + 題數扣點，Upstash 記錄 | 新增 `app/api/billing/*` |
| 商用託管 | Vercel Hobby | Vercel Pro | 帳務設定 |

零閒置流量原則在多用戶版本更重要：每張通行證有題數上限，檢視頁維持現有的背景暫停與退避。

## 五、主要風險與對策

| 風險 | 嚴重度 | 對策 |
|---|---|---|
| B2C 使用頻率低，撐不起被動收入 | 高 | 練習模式拉高頻率；三波升學季疊加；Tier 1 月費補位 |
| 被貼上「面試作弊工具」標籤 | 高 | 明確不做面試中提詞；行銷只講「賽前練習」與「前線員工」；文案不用「作弊」字眼 |
| 比賽規則禁止上台用 AI | 中 | 主打練習，上台模式當附加價值 |
| 開源 repo 讓人自架免費用 | 中 | 自架者本來就不付錢；付費版賣「不用架、有練習模式、有組織帳號」 |
| ChatGPT 語音模式免費替代 | 中 | 差異化在「只用你的資料、不捏造數字」、舞台 UX、隊友同步、繁中口語稿 |
| Tier 1 需要業務人力，和「半被動」衝突 | 中 | Phase 0-2 只做 1-2 個試點，Phase 3 再用數據決定要不要投入 |
| OpenAI 模型停用或漲價 | 低 | 模型名集中在 `lib/openai.ts`，一處可換 |
| 正職時間吃掉副業 | 高 | 每階段有門檻，不達標就停，不做無止境的功能 |

## 六、本週就做的事

1. 黑客松結束 24 小時內，寫下使用數據和隊友回饋。
2. 錄一支 60 秒 demo 影片（手機拍即可）。
3. 列 10 個訪談對象，先約 3 個；其中至少 1 個是展場或業務端的人。
4. 開一份試算表記錄：每週投入時數、收入、付費人數。

## 驗證方式

每個 Phase 結束時對照通過門檻：
- Phase 0（10 月中）：付費手動服務 ≥ 3 人或預約 ≥ 30 人
- Phase 1（10 月底，推甄季前）：自助付費 ≥ 10 人含 3 個陌生人，或 1 家 B2B 二次付費
- Phase 2（隔年 4 月）：旺季單月 ≥ NT$10,000，自然流量 ≥ 30%
- Phase 3（隔年 9 月）：連續 3 個月 ≥ NT$15,000，每週投入 ≤ 3 小時
